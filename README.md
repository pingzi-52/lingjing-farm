# 灵镜档案 · 林缘农场

## 项目介绍

一款基于浏览器的 2D 像素农场经营游戏。玩家可以在农场、小屋、森林与小镇之间探索，体验种植、采集、交易、居民委托和制作的日常循环。

- **技术栈：** TypeScript、Phaser 3、Vite、Vitest。
- **核心玩法：** 作物种植与收获、时间与天气变化、背包及储物箱、商店交易、居民委托和物品制作。
- **工程实现：** 将游戏规则与场景表现分离，通过共享游戏会话管理跨场景状态；使用浏览器本地存档，并支持旧版本存档兼容与备份恢复。
- **测试与运行：** 使用 Vitest 覆盖时间、经济、存档、地图和会话等逻辑；下方提供本地启动和测试命令。
- **当前状态：** 单人小型测试版，游玩进度保存在当前浏览器；每日订单目前仅有领域原型，尚未接入游戏。

原创 2D 浏览器农场模拟经营游戏。当前本地小型测试版包含农场、林缘森林与溪桥镇，可种田、交易、每日采集、完成三位居民的委托、制作菌菇餐与农场提灯。保留完整存档、农舍木箱、游戏时钟、体力、天气和昼夜变化。

试玩地址：[林缘农场网页测试版](https://lingjing-farm.brownarrow2.chatgpt.site)（部分网络可能无法访问）。游戏支持电脑键鼠和手机触屏；存档按设备和浏览器分别保存，换设备可导出/导入文件。详情见 [公网试玩说明](docs/PUBLIC_DEPLOYMENT.md)。

## 操作

| 按键 | 功能 |
|---|---|
| W / A / S / D 或 方向键 | 移动角色 |
| E | 与田边禾木交谈；农舍门前进入；室内床旁睡觉 / 木箱旁存取 / 门口出屋；田里收获 |
| Q | 农场任务手记；靠近禾木可领取种子与交付首份收成 |
| F | 农场农务手记：田地状态、浇水统计和四季作物资料 |
| G | 小屋家具布置：选物、点击预览、确认摆放或收回；关闭放弃未确认位置 |
| Space | 农场对当前目标使用已选工具或种子 |
| X | 农场还原无作物的空耕地，消耗 1 体力；有作物时拒绝清理 |
| L | 只读区域手记：森林/小镇方位图（你、居民、资源、出口），区域和三项委托状态 |
| K | 随身制作菌菇餐 / 农场提灯，也可吃饭恢复体力 |
| M | 声音设置：静音、操作/风雨音量、试听；标题与室内也可打开 |
| T | 回到标题界面 |
| Enter | 标题界面继续/开始游戏 |
| N | 标题界面新游戏 |
| B / I | 集市 / 背包；菜单打开时暂停农场 |
| Esc | 关闭对话、手记、集市或背包 |
| 1–8 / 左键 | 选择快捷栏 / 点击相邻地块使用工具或种子；点击快捷栏仅选物 |
| R | 标题界面恢复上一份有效存档 |
| S | 标题界面存档管理：导出、选择文件预览/确认导入、导出导入前备份 |

背包前8格为快捷栏；后排物品点选后，再点前8格可交换。收获物和采集材料可在背包出售。V7存档保存金币、日期、时刻、体力、背包、储物箱、耕地、作物、三项委托、每日已采集点、永久提灯及家具收纳/布局；V1至V6兼容读取，写入升级前备份。已有存档时，新游戏需要再次按N确认。刷新后从农场继续，角色所在区域和位置不持久化。

出生点东侧找到禾木，靠近按E领取3颗当季种子。每天照料后回小屋休息，收获后交付指定作物1份，获得120金，余下收成保留。任务不重复领奖，无期限。对话和Q手记暂停农场；若旧田占满商人全部候选位置，Q改用便笺联络，不删除旧田。

从农场西侧林间路步行到森林找岚：3野蘑菇换80金；从农场东侧乡道步行到溪桥镇找阿榆：6树枝和4溪石换140金与提灯配方。经过路口自动保存，短暂淡出后从相应入口进入；顺来路返回。室内先正常出屋，L仅查看区域和委托。森林9个点每日各采一次，每次2体力，睡觉恢复；2野蘑菇做1份餐，吃后恢复25体力。提灯需完成阿榆委托，再花4树枝和3溪石，只建一次。委托和制作从随身背包扣材料，失败保存会回滚。

区域衔接设计与本轮验收范围见 [docs/WALKING_AREAS.md](docs/WALKING_AREAS.md)；旧菜单出行的五日验收仅证明经营流程，步行版以本轮独立证据为准。

森林与小镇按L可看当前区域方位图，已采点会隐藏、次日恢复；查看时暂停，地图下方可滚动查看委托。地图仅供查看，仍需沿路步行。截图与最新663项测试、实机记录见 [docs/AREA_MAP.md](docs/AREA_MAP.md)。

换电脑携带游玩进度：T保存回标题→S导出文件；在另一电脑标题S选择文件，核对预览后确认导入，Enter继续。自动保存不会覆盖导入前副本，可用“导出导入前备份”找回最近一次替换前的有效档。文件仅在本地处理，无云存档。

每天06:00开始，活动7秒推进10分钟，22:00停钟；床睡觉才进入次日并恢复100体力。菜单、标题和后台暂停。开垦/浇水/播种成功消耗2/2/1体力，重复已耕/已湿免费，收获和移动免费。雨天自动浇水；重载不重掷天气。

首次按键/点击后启用声音。操作声与轻量风雨声可分别调节，暂无背景音乐；设置独立保存，不改变游戏存档。后台和菜单暂停环境声。快捷栏显示1–8标号、堆叠数量及统一物品图标。

农舍通常位于北侧主路尽头，旧存档若已种植对应空地，房屋会避让到其他预留位置；所有候选已被种植时，原休息点保留为小屋入口。屋内木箱两边各24格，可存取1件或全部，保存失败会还原物品。菜单打开时场景暂停。

独立美术预览：`showcase.html?style=cainos-farm`；农舍候选：`showcase.html?style=cainos-home`。

## 目录结构

```
src/
├─ main.ts               入口：挂载 Phaser 游戏
├─ game/
│  ├─ config.ts          全局常量（TILE、场景键、视野）
│  ├─ createGame.ts      Phaser 实例创建 + 场景注册
│  ├─ scenes/            Boot / Title / Farm 场景
│  ├─ entities/          Player（角色）
│  └─ systems/
│     ├─ GameSession.ts  跨场景共享状态（单一事实源）
│     └─ placeholderAssets.ts  程序化占位像素素材
├─ domain/
│  ├─ models/            数据模型类型（日期/季节/存档）
│  └─ services/          TimeService / EconomyService（纯逻辑）
├─ data/maps/farm01.ts   原创「青禾农庄」地图（36×24）
├─ persistence/save.ts   localStorage 存档管理器
├─ ui/                   UI 层预留接口
└─ styles/               全局样式
tests/                   Vitest 单元测试
```

## 架构约定

- 游戏规则在 `domain/services`（纯逻辑可单测），**不写在 UI 事件回调里**
- 金币 / 日期等状态只存在于 `GameSession`（模块级单例），场景切换不重置
- 场景只读取会话状态做表现，不持有权威数值
