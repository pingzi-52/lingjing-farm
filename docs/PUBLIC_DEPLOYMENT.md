## 操作与存档

- 电脑继续使用原键盘和鼠标操作。
- 手机点标题页开始，方向键按住移动；点交互、使用工具、背包、集市、地图、制作等按钮。快捷栏和相邻田块可直接点按。
- 手机横竖屏自动缩放；菜单在游戏画面内滚动。触屏方向在松手、取消、失焦、切换场景、屏幕旋转或打开菜单时释放。
- 存档仍在当前设备、当前浏览器、当前网址的 localStorage 中，不自动跨设备同步。
- 换设备：保存回标题，点「存档管理」导出文件，在另一设备同一入口选择文件并确认导入。本地开发网址的存档也需要这样转入公网网址。
- 不包含账号、云存档、多人联机，也不依赖本机保持开机。
