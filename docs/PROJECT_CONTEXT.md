# 《灵镜档案》项目上下文

## 项目定位与当前阶段

原创单人 2D 浏览器农场模拟游戏，原项目名《四季田园》，当前场景名为林缘农场。长期目标是温暖、统一、可长期经营的俯视像素农场，参考《星露谷》的品质与生活节奏，不复制其美术或内容。

当前阶段是**可试玩的小型测试版**，先保证「种田—探索采集—居民委托—制作—回家」的完整流程，再完善美术、地图与引导。用户已授权继续自主推进，早期「只核对素材、不写代码」是已结束阶段，不应据此阻止当前合理的小范围实现。普通实现不必反复要求用户确认；购买、公开发布及明显不可逆操作仍需明确授权。

## 架构与素材接入

| 位置 | 职责 |
|---|---|
| `src/game/systems/GameSession.ts` | 跨场景权威状态与事务入口 |
| `src/domain/services/` | 种植、时间、交易、每日生活、探索与委托等可单测规则 |
| `src/persistence/save.ts` | 严格校验、迁移、localStorage 读写、备份与恢复 |
| `src/game/scenes/` | Boot、Title、Farm、Home、Forest/Town 的呈现与交互 |
| `src/data/maps/` | 地图与道路连接数据；避免删除旧田 |
| `src/ui/` | 背包/集市、对话、制作、只读区域手记、声音设置 |
| `src/game/systems/farmArtAssets.ts` | 加载正式图片和 atlas 帧表 |
| `src/game/systems/placeholderAssets.ts` | 保留占位与回退纹理，禁止整文件覆盖既有成果 |
| `public/farm-assets/` | 分类 PNG、Cainos 免费包、原创补件及来源/授权文档 |
| `tests/` | 规则、迁移、地图可达性、资源合同与交互辅助逻辑测试 |

正式资源以静态 PNG 和 atlas JSON 加载，通过 `import.meta.env.BASE_URL` 兼容资源根路径。原图与帧表分开保存；多格树木、角色、提灯应等比缩放，以脚底定位，不把源图强拉成格子比例。已接受的土壤使用 `original-addons/v4/soil-patches-v3.json`，不要误切回旧裁切表。

场景只负责表现和输入，数值操作走 GameSession/领域服务。跨区不重新初始化会话、不推进日期、不刷新每日资源。菜单、隐藏页面与过场暂停移动、时钟和环境音；场景关闭必须清理自己的监听、菜单及碰撞体。

## 存档与兼容边界

V7 保存金币、日期、背包、木箱、耕地与作物、时刻/体力、原收成任务、两项探索委托、当日已采集点、永久提灯和家具收纳/布局。当前**不保存玩家精确位置/所在区域**，刷新从农场继续。

GitHub保存开发项目，不自动同步个人游玩档；不同电脑/浏览器/origin的数据仍独立。现在可在标题S导出文件，并在另一浏览器预览/确认导入，支持严格V1–V6迁移；没有云存档。替换前的原文另存before-import副本，正常自动保存不更新，有效副本可从S导出。不得上传浏览器profile或擅自读取用户个人档。保持127.0.0.1:5175便于继续同一浏览器进度。

现有耕地/作物、物品、金币、任务必须保留。失败保存不能吞物、扣体力、发重复奖励或换图。需要变更存档合同就显式加版本、兼容迁移与边界测试，不能放宽校验来绕过失败。

## 美术方向与未完成项

保持同一暖色俯视农场风格：自然草地/道路过渡、可读水岸、完整树木轮廓、有限花草点缀、清晰农田和人物脚底层级。先把现有区域做好，避免一次引入大量不统一的素材包或用程序噪点代替专业素材体系。

Cainos 素材和原创补件的来源、许可证、提示词保留在资源目录；不能为整个混合素材库随意添加统一授权。原创补件为高分辨率像素风插画，不代表严格原生 16/32px 动画素材。禁止引用《星露谷》原版美术。

当前限制：新居民仍静态驻点；森林构图、地图引导、小镇建筑差异和人物风格有打磨空间；其他季节田间作物仍沿用旧表现。无作息、好感、钓鱼、节庆、工具升级、长期故事和背景音乐；未做外部玩家时长、长期经济平衡或全面跨浏览器验收。

下一步先实际试玩和修反馈，再改善地图可读性/NPC 动作/其他季节素材，之后扩充系统。详细路线见 [AUTONOMOUS_ROADMAP.md](AUTONOMOUS_ROADMAP.md)。
