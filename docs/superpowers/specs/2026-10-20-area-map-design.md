# 森林与小镇区域地图

目标：让首次进入森林或小镇的玩家能从 L 手记判断自己、居民、剩余采集点与回农场出口的位置。

沿用 PROJECT_CONTEXT 与 AUTONOMOUS_ROADMAP 已授权的普通质量改进。本轮选择在现有只读手记内增加当前区域地图；常驻小地图会遮挡 512×384 的游戏画面，自动寻路会改变操作与碰撞行为，均不纳入本轮。

地图读取当前场景的 ExplorationMap、玩家世界坐标与当日 picked ID，打开时生成快照。按真实障碍、道路和建筑绘制地形；用形状和文字区分玩家、居民、出口、树枝、溪石和蘑菇。已采资源不再标出，次日按会话数据恢复。森林东口、小镇西口的位置来自 areaExits；不能把旧 start 坐标当成出口。

TravelMenu 接受可选快照 getter，农场与室内继续使用原有摘要。地图没有点击行为，通过现有 PausePanel 保持暂停、焦点、Esc/L 关闭与清理合同。场景只提供数据，地图模型为纯函数；存档、任务、权威地图和自然步行过图均保持既有合同。

研究：ExplorationScene 已公开 worldMap/player，refreshState 从会话读取资源状态；TravelMenu 继承 PausePanel 的 DOM 与暂停生命周期；areaConnections 定义出口，AreaPassage 另外绘制路口接近道路。将这段道路格选择抽成纯函数复用，确保手记与场景展示一致，同时保留旧田 reserved 过滤。

验证：单测核对地图坐标、资源筛选/恢复、建筑边界、路口道路、旧田避让、输入不变；全套测试与构建；隔离浏览器实际打开森林/小镇手记、移动后重开、采集后重开、暂停/恢复、菜单点击不传送与四向道路回归。记录截图及实际结果，不用历史657项测试代替新验证。
