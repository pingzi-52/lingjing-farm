# 区域地图 Implementation Plan

> 在当前会话逐项执行，遵守先测试再实现。项目既有自主推进与不顺手提交约定优先；本轮保留本地可审阅改动。

**Goal:** 在森林和小镇 L 手记中展示与真实场景一致的只读定位地图。

**Architecture:** 纯地图模型读取现有场景快照；独立 DOM/SVG 组件渲染。TravelMenu 通过可选 getter 接入，PausePanel 继续负责交互生命周期。

**Tech Stack:** TypeScript、Phaser 3.90.0、原生 SVG、Vitest；不增加依赖。

## Global Constraints

- 保存 V6 与原有步行过图；不改变权威地图、资源 ID 或个人存档。
- 不引入点击传送、自动寻路或常驻遮挡。
- 沿用木色界面，地图标记同时使用形状与中文图例。
- 不提交、推送或公开发布；不购买或替换素材。
