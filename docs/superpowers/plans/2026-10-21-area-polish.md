# 森林与小镇场景打磨 Implementation Plan

**Goal:** 在保持既有短流程的前提下，改善森林视线与小镇建筑辨识度。

**Architecture:** 纯森林空地处理与展示计划，独立Phaser场景装饰模块；只扩展探索场景，不改农场与存档系统。

**Tech Stack:** 现有Phaser/TypeScript/Vitest；Cainos与原创PNG；零新依赖。

## Global Constraints

- 保留全部现有未提交工作；不commit/push/release。
- 资源ID/坐标、居民坐标、原道具碰撞、建筑足迹、步行开口不变。
- 图片通过内置imagegen生成并保存至public，保留来源与原字节；静态帧裁切不改PNG。
- 无新存档字段或领域规则；测试必须先失败再实现。
